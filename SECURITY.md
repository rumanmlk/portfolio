# Security policy

This repository is a static personal portfolio. It has no backend, database, user accounts or contact form.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately by email to [rumanmlk123@gmail.com](mailto:rumanmlk123@gmail.com) with "Security report" in the subject. You can also use the repository's **Security** tab and choose **Report a vulnerability** when it is available.

I will acknowledge a report within a few days. Because the site is static and personal, fixes are made on a best-effort basis.

## Scope

In scope: the code in this repository and the deployed site at rumanmalik.vercel.app (for example cross-site scripting, unsafe headers, or leaked secrets).

Out of scope: vulnerabilities in third-party services (Vercel, GitHub) or in dependencies without a way to exploit them here; report those upstream.
